# Winner Bot Mobile App (Planned)

Planned: Flutter-based app that displays live and OTC signals from the backend API. No auto-trading.

Features:
- Latest signals list (pair, timeframe, action, confidence, reasons)
- History view
- Pair/timeframe filters
- Subscription status (trial, monthly, lifetime)
- Contact/Terms/Privacy links

Build targets:
- Android APK and AAB (Play Store ready)

CI/CD:
- GitHub Actions job will be added to build APK/AAB once the Flutter scaffold is committed.
